# Backlink Strategy Engine

A powerful desktop application for automating link building outreach.

## Features

- 📥 **Domain Import** - Import domains from Scrapebox CSV exports
- 📊 **Ahrefs Integration** - Enrich domains with DR, traffic, and backlink data
- 🔬 **Website Analysis** - Automatically detect contact methods and extract guidelines
- 🤖 **AI-Powered** - Use Claude or GPT for personalized email generation
- 📧 **Outreach Management** - Queue, send, and track outreach emails
- 🔗 **Link Tracking** - Monitor your acquired backlinks
- 📈 **Analytics** - Track response rates and campaign performance
