Connect an account (secrets are encrypted, never shown again)

wordpress_hub: WP Admin → Users → Profile → Application Passwords → add "Buzz Scouts Engine" → paste WP username + that password.
shopify_hub: Shopify Admin → Settings → Apps → Develop apps → Create app → Admin API scopes: write_content, read_content → Install → paste the Admin API access token as password (username can be empty).
social_engine: URL of the brand's traffic-engine service (e.g. https://tshirtcrisis-social.up.railway.app) + its ENGINE_API_TOKEN as password.
imap_inbox: the outreach mailbox where replies and journalist-request emails arrive (use an app password).

Launch Kit auto-publishers (password field = the token):
telegraph: nothing to do, created automatically. writeas: optional token, empty = anonymous posts.
blogger: Site/API URL empty, IMAP host field = Blog ID, username = client_id:client_secret of a Google OAuth app, password = refresh token (Blogger scope).
wordpress_com: Site URL = yoursite.wordpress.com, password = OAuth2 access token. tumblr: handle = blog name (e.g. mrcraxoutwrites). Register an app at tumblr.com/oauth/apps, open api.tumblr.com/console, paste its consumer key + secret, Authenticate, then show keys: username = consumer_key:consumer_secret, password = token:token_secret.
hashnode: IMAP host field = publication ID, password = personal access token. devto: password = API key (Settings → Extensions).
mastodon: Site URL = instance (https://mastodon.social), password = access token. bluesky: handle = you.bsky.social, password = app password.
github_pages: handle = GitHub user, IMAP host field = repo (empty = user.github.io), password = fine-grained token with Contents: write.
